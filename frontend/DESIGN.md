# Heli Monitor 前端设计规范

本轮以 v1.0.2 为基础，仅调整前端视觉与交互，不变更服务端接口、权限或数据计算口径。

## 品牌与主题

- 标识为原创 H / M 线条与监测波形组合，保留可配置的中文品牌名称及 HELI MONITOR 英文署名。
- `src/styles.css` 维护唯一的全局颜色、字号、间距和组件规范。新增页面优先使用语义变量，避免复制颜色常量与渐变。
- 浅色使用白色面板、浅灰画布、科技蓝强调色；深色使用低饱和蓝灰画布与分层面板。
- `src/stores/theme.ts` 管理主题；初次访问跟随系统偏好，手动选择保存在本地。登录页和顶部工具栏使用同一主题按钮。

| 变量 | 含义 |
| --- | --- |
| `--canvas` / `--surface` / `--surface-subtle` | 页面、面板、次级背景 |
| `--text-primary` / `--text-secondary` / `--muted` | 主信息、次信息、辅助说明 |
| `--brand` / `--brand-soft` | 主色及低对比背景 |
| `--success` / `--warning` / `--danger` | 正常、需关注、故障 |
| `--border` / `--divider` | 组件边框及内容分隔 |

## 布局与组件

- 桌面使用可折叠导航、64px 顶栏和自适应内容区；手机使用可收起的抽屉导航。
- 面板以细边框为主，避免重阴影。12px 面板圆角、8px 控件圆角、24px 页面标题保持统一。
- 页面标题、说明与操作分层；操作栏可换行，筛选控件不挤压数据区域。
- 小屏宽表只在表格内部横向滚动，解除固定操作列以防遮挡数据，保留全部操作入口。
- 弹窗由主体区域统一承担纵向滚动，避免历史图表的双重滚动条。
- 主要操作突出、危险操作使用红色语义；保留现有确认流程及权限控制。
- 保留键盘快捷搜索、可见焦点、跳到主要内容、密度切换及减少动态效果偏好。

## 图表

`src/composables/chartAppearance.ts` 维护统一的图表色板、坐标轴、分隔线、图例文字与提示框。主题变化只更新图表呈现，不改变原始点、时间范围及统计口径。历史图表切换主题采用局部选项合并，保留缩放及图例选择。

数据继续使用逐次原始记录和平滑线条；不要为美化效果采样、补成功值、生成示例指标或隐藏故障状态。

## 检查要求

运行 `npm run lint`、`npm test`、`npm run build`；在桌面及手机检查浅深主题、表格横向滚动、任务历史弹窗、筛选、导航折叠、快捷搜索和只读操作入口。构建通过后再替换前端容器。
