# 探测任务与历史数据

## 任务操作

任务列表支持类型、业务、启停状态和名称/目标搜索。每行提供立即探测、历史数据、启停、复制、编辑和删除。
复制的任务默认暂停，认证信息在服务端复制，界面只显示掩码。删除任务会永久删除其相关探测历史，请在操作前确认。
批量启停和批量探测每次最多 100 项。未勾选时，批量探测使用当前筛选范围内的启用任务；勾选后仅探测所选任务。
批量探测由 Celery 异步执行并显示进度，关闭结果窗口不取消任务。刷新页面可以继续查看该浏览器会话的批次。
暂停任务可以手动立即探测；自动调度和持续告警暂停。重新启用后状态先变为待探测，再由新结果确认状态。

周期范围 5–86,400 秒，超时范围 1–30 秒且必须小于周期，连续失败/恢复阈值范围 1–100。
首次真实失败建立事件；失败阈值用于状态升级，恢复阈值用于确认恢复。

## 各类型选项

- HTTP/API：GET、HEAD、POST、PUT、PATCH、DELETE、OPTIONS；可配置请求头、查询参数及认证。
  请求体可选无、JSON、表单、原始文本，编辑时保留原类型。
  期望状态码留空接受全部 2xx；可指定多个状态码、关键字、正则及 JSONPath 断言。
  JSONPath 示例：`[{"path":"$.status","value":"ok"}]`，省略 value 则检查路径存在。
  支持 Bearer、Basic、API Key、OAuth2 客户端认证；认证值和常见敏感请求头加密保存。
  可选择重定向和 TLS 校验，重定向逐跳检查目标并限制次数，跨源时不转发认证信息。
- TCP：连接检测，可发送文本并匹配返回；可选择将字面的 `\r\n` 等转为控制字符。
  返回内容跨多个网络包时累计匹配，读取量默认 4 KB，高级连接选项可配置 receive_bytes（256–65,536）。
- PING：发送 1–10 次，可配置允许丢包率（0–99%），默认为 0。总探测等待受超时控制，超时不再乘以发送次数。
- DNS：A、AAAA、CNAME、MX、TXT、NS、SRV；支持自定义 DNS 服务器 IP 及期望记录列表。
- SSL：域名可省略 443 端口；支持 IPv6 目标。预警天数 1–3,650 天。
  进入预警期可选择仅页面预警、降级提示或判定探测失败；通知按关联告警规则和通知渠道发送。
  任务历史弹窗顶部显示有效期天数及到期时间；汇总历史趋势页不显示证书卡片。
- PostgreSQL、MySQL/MariaDB、SQL Server：数据库、只读账号、密码、单条只读 SELECT/WITH 查询。
  禁止多语句及明确的写入语句。期望结果留空取消值比较，只验证查询成功。
  PostgreSQL 设置只读事务与语句超时；MySQL 的 TLS 开关实际启用并校验证书。
- MongoDB：使用 ping 验证；支持开启/关闭认证、认证数据库及 TLS。

所有数据库探测应使用目标系统的专用只读账号；查询解析检查不能替代数据库账户权限。

## 历史数据

监控中心 → 历史数据展示全部任务；任务行的历史数据按钮自动按该任务筛选。
支持近 1 小时、6 小时、24 小时、7 天、1 个月及自定义起止时间，最长 30 天。
提供成功率、成功/失败次数、响应统计、趋势图、分页明细及单次结果详情。
汇总和趋势基于完整筛选结果，不局限于当前页；没有记录的时段不补成成功。
任务删除归档后，历史数据仍可查询。

清理策略至少保留最近 31 天的原始记录；超过 31 天的数据再按系统设置的最低保留条数清理。
旧版本已清理的数据无法恢复，页面显示所选范围实际存在的首末记录时间。

## 新增 API

- POST `/api/v1/monitors/run-batch/`：`{"ids":["UUID"]}`，返回 202 和批次 token。
- GET `/api/v1/monitors/batch-status/?token=...`：返回完成数、成功/失败/跳过数和各项结果；批次绑定创建用户，token 有效期 2 小时。
- POST `/api/v1/monitors/bulk-enable/`：`{"ids":["UUID"],"enabled":false}`。
- POST `/api/v1/monitors/{id}/copy/`：创建暂停的副本。
- GET `/api/v1/monitors/options/`：任务表单的业务、标签和类型选项。
- GET `/api/v1/monitors/history/`：monitor、business、monitor_type、success、search、checked_after、checked_before、page、page_size。
  返回分页明细及完整范围的 summary、series、实际时间范围。
- 旧 test-all 同步接口仅用于预计总超时不超过 45 秒的小批量调用；界面使用异步接口。

OpenAPI 可在 `/api/v1/schema/` 获取，界面类型位于 `frontend/src/api/monitorTypes.ts`。

历史记录保存探测时的任务名称、类型、目标及业务信息快照，后续编辑任务不会改写已保存的元数据。旧记录在首次编辑前冻结当前可确认的信息，无法追溯旧版本已发生的改名或改目标。任务目标/类型/配置变化时重新进入待探测状态；编辑前已经开始的旧探测只记入历史，不覆盖新配置的当前状态。

## 批次容错与结果筛选（第二轮复查）

队列提交中断时仍返回 202 和完整批次 token，保留已提交任务的进度；未确认提交的任务以 FAILURE 和通用错误说明返回，不泄漏队列连接信息。提交失败的任务不会自动重复提交。提交后超过 31 分钟仍无结果的任务结束等待并提示检查工作进程。

页面遇到暂时网络错误、服务器错误或限流时每 5 秒重试，保留当前会话 token；无效 token 或无权访问时停止。切换到其他资源菜单再返回时恢复进度，旧页面请求不会覆盖当前状态。

结果列表与 summary 的 checked_after、checked_before 必须为有效日期，起始早于结束，monitor_type 必须为支持类型，无效条件返回 400。summary.by_type 按执行时保存的类型快照分组，旧版本没有快照的记录使用当前已知类型。

历史趋势页面及任务下拉选项不再展示已删除任务；历史接口的图表、统计和明细均排除已删除任务。已删除任务的存量数据按最新永久删除策略清理。

任务删除策略更新：删除任务时永久清除任务、探测结果、状态迁移、故障事件、关联通知与任务链路节点，移除任务关联，但保留其他任务、共享业务与通知渠道。删除行为保留最小审计记录。执行中的旧探测不允许重新生成已删除任务的数据。已归档任务执行一次清理后不再保留于业务数据库。

历史图表改为原始时间点：history 接口的 series 包含查询范围内全部原始记录（id、monitor、at、latency_ms、success），bucket=raw，不进行分钟/小时分桶、平均或抽样。results 仍为分页明细，summary 仍为范围统计。页面按任务分别绘制每次响应值及成功/失败散点，支持时间缩放；空白时段不补充探测数据。

监控中心复查（2026-10-22）：总览与任务列表统一状态判定；所属业务停用/归档时任务显示暂停，待探测任务不沿用旧结果标记可用。大屏的 SLA 请求失败不阻断监控数据，面板明确提示不可用；响应趋势按任务和实际时间分别绘制，避免不同任务连成同一条曲线。总览补充暂停和未知状态，并在无可评估数据时显示暂无评估。业务链路接口拒绝跨链连线、自连接、循环依赖，带连线节点不能直接移动到其他链路，PATCH 同样适用。

资产管理优化（2026-10-22）：业务分组禁止循环父级及同级同名；有关联下级或业务的分组禁止直接删除。业务系统 SLA 目标限定 0~100，归档自动停用；仍有探测任务或业务链路时，删除返回 400 并提示先调整关联，不级联删除任务。标签颜色接受 #RGB / #RRGGBB，保存为大写。资产列表增加可读关联名称、标签及探测任务数，并支持分组、启停、归档筛选。无实际调度效果的服务时间选项从表单移除，原字段仍保留为元数据。

GET /api/v1/business-systems/options/ 需 asset.view，仅返回 business-groups（id/name/parent）、departments（id/name）、users（id/username，启用用户）和 tags（id/name/color），不返回用户密码、邮箱或组织管理数据。用于资产表单，避免额外依赖 iam.view。列表新增只读字段 group_name、department_name、owner_name、tag_names、monitor_count；业务分组增加只读 parent_name。

大屏响应趋势时间周期：默认近 12 小时，可切换 1/6/12/24 小时、3/7 天或 1 个月。按所选范围加载 history 原始点，取消最新 80 条限制，时间轴使用实际查询边界；性能热点和样本成功率对应所选周期，顶部明确标注的 24H 指标与 SLA 仍保持 24 小时口径。切换期间显示加载状态，旧请求不能覆盖新周期。实时推送及定时刷新继续更新当前周期。
