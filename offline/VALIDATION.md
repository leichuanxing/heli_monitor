# Heli Monitor v1.0.3 离线安装验证记录

日期：2026-10-30。目标平台：EL9 x86_64；应用与依赖镜像：linux/amd64。

## 已验证通过

- Bash 语法检查、Python 静态错误检查、8 项安装器回归测试。
- 132 个离线 RPM 在独立 EL9 安装根目录完成断网依赖解析、事务检查及事务测试。
- 最终包解压后逐文件 SHA-256 校验通过。
- 使用包内安装器，在独立目录、Compose 项目和 18083 测试端口执行真实交互安装，完整经历全部 10 个安装阶段。
- 按顺序输入持久化目录、应用端口、账号、密码并确认；密码输入隐藏，安装完成后在交互终端显示。
- 新建管理员可以通过登录接口获取令牌，并访问认证后的监控总览接口。
- PostgreSQL、Redis 均为指向所选目录的 bind mount。
- 删除并重建测试容器后再次登录成功，证明数据及账号保持。
- 安装密码未出现在安装日志或应用 .env 中。
- 已有 Docker 的存储配置、生产容器 ID 未改变；测试容器已停止移除，测试目录保留作验证证据。

## 修复并回归

首次实装发现 Compose run 不支持 --pull 参数。已改为服务级 pull_policy: never，并保留 up --pull never，重新完整安装验证通过；未跳过失败安装阶段。

## 验证边界

已有 Docker 的完整安装流程已实际验证。无 Docker 分支完成脚本回归、daemon.json 合并与旧数据保护测试、RPM 离线事务验证；没有在一台全新裸机上实际启动新安装的 Docker 服务。安装器不会修改现有 Docker 存储目录，也不自动迁移旧 Docker 数据。

本包不自动配置防火墙、安全组或内核参数。外部访问应放行所选端口。验收主机 Redis 输出了内存 overcommit 提示，服务健康及持久化验收通过；宿主机参数按运维策略单独配置。

包内仅有源码、运行镜像、Docker/系统依赖和安装脚本，不包含生产数据库、生产 .env 或安装时输入的密码。镜像具体 ID 见 images/manifest.txt。
